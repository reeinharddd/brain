
# Command: /init

> Initialize a local project with brain repo rules and instructions.

## Description

This command initializes the current project with Brain-aware context and keeps the project aligned with the Go CLI and daemon flow.
It generates a stack-aware project context file at `.brain/skill-context.md` and prepares the project for IDE integrations.

## Execution

Use the command from a supported agent or CLI session:

```text
/init
```

## How to use

Type `/init` in any agent that supports slash commands. If you need to refresh generated Brain configs afterwards, run `brain sync`.
