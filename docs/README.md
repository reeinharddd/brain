## Quality Principles

1. Factual, not aspirational by accident
2. Current, not historical unless explicitly archived
3. Linked, so decisions and designs are traceable
4. Canonical, so active ADRs override stray notes

## Contribution Rules

1. Put decisions in `docs/adr/`.
2. Put system contracts in `docs/architecture/`.
3. Update [INDEX.md](/home/reeinharrrd/Work/Personal/brain/docs/INDEX.md) when adding a new canonical entry point.
4. Keep documentation in English and aligned with the unified schema.
