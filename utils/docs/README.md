## Non-Canonical Working Notes

This directory is reserved for temporary or generated working notes produced by IDEs, LLM sessions, or local automation.

Rules:

- Files here are not part of the canonical documentation baseline.
- Nothing in this directory overrides `docs/`.
- Important decisions must be promoted into `docs/adr/` or `docs/architecture/`.
